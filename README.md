# お茶室 春月庵 ホームページ

裏千家の茶道教室「お茶室 春月庵（春月庵 in 横浜）」の案内用ウェブサイトです。
このファイルは、サイトの運営を引き継ぐ方のための説明書です。

- 公開URL: https://shungetsuan.github.io/
- 公式X（イベント告知など）: https://x.com/shungetsuan
- GitHub: https://github.com/shungetsuan

## 1. このサイトについて

- **目的**: 教室の案内ページ。稽古日、料金、講師紹介、見学案内などを掲載します。
- **想定する読者**: 茶道に興味のある一般の方、入門を考えている方。
- **デザイン方針**: 和紙風の落ち着いた雰囲気、月をモチーフにした意匠（「春月庵」の名に由来）。
- **言語**: 日本語が中心。講師紹介は日本語・英語をタブで切り替えられます。
- **費用**: GitHub Pages（無料）で公開しているため、サーバー代はかかりません。独自ドメインは未取得です。

## 2. ファイル構成

| ファイル／フォルダ | 役割 |
| --- | --- |
| `index.html` | トップページ（教室案内・稽古日・料金・講師紹介・特色） |
| `tokushoku.html` | サブページ「春月庵の特色」（過去のイベントとXの紹介） |
| `style.css` | 見た目（色・文字・レイアウト）を決めるファイル |
| `assets/` | ファビコン（ブラウザのタブに出る小さなアイコン）などの画像 |
| `README.md` | このファイル |

ページの文章を変えるときは `index.html` などのHTMLファイル、見た目を変えるときは `style.css` を編集します。
HTMLとCSSは同じ階層に置く必要があります。フォルダの中に入れないでください。

## 3. 公開のしくみ

- リポジトリ名は `shungetsuan.github.io` です。この名前にしているため、公開URLが `https://shungetsuan.github.io/` になります。
- GitHubの `Settings` → `Pages` で、`main` ブランチの `/ (root)` を公開する設定にしています。変更しないでください。
- リポジトリにファイルを保存（Commit）すると、1〜2分ほどで公開ページに反映されます。

## 4. 内容を更新する手順

1. パソコン上でHTMLやCSSを編集して保存します（文字コードは **UTF-8**）。
2. 編集したファイルをブラウザで開き、表示を確認します。
3. GitHubのリポジトリを開き、`Add file` → `Upload files` を選びます。
4. 変更したファイルを、**同じファイル名のまま**ドラッグ＆ドロップします（同名ファイルは上書きされます）。
5. `Commit changes` を押して保存します。
6. 1〜2分待ってから公開URLを開き、`Ctrl + F5` で最新の表示を確認します。

誤字の修正など小さな変更は、リポジトリ上でファイルを開き、鉛筆アイコン（Edit this file）から直接編集することもできます。

### つまずいたとき

- 反映されない: 数分待って `Ctrl + F5`。リポジトリの `Actions` タブで処理が完了（緑のチェック）しているか確認します。
- デザインが崩れる: ファイル名・パスの大文字小文字が、HTMLの記述と一致しているか確認します（GitHub Pagesは大文字小文字を区別します）。
- 404になる: `index.html` がリポジトリの一番上の階層にあるか確認します。

## 5. 更新が必要になりやすい内容

- 稽古日・時間、料金、見学の案内（`index.html`）
- 講師紹介・役職（`index.html`、日英タブの両方）
- 特色ページの文章、過去のイベント、今後のイベント情報（`tokushoku.html`）
- 写真の追加（`assets/` に画像を入れ、HTMLから読み込みます）

イベントなど更新頻度の高い情報は、サイトではなく公式Xで発信し、サイトからはXへリンクする運用にしています。
